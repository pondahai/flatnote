# wripix

A WYSIWYG HTML notebook. Your note is just a file — no backend, no database, no API.

**線上版：** https://pondahai.github.io/wripix/

---

## 這是什麼

一個所見即所得的網頁編輯器，寫出來的筆記**就是一個 HTML 檔案**。

HTML 同時是「資料」和「呈現」。筆記存出去以後，不需要這個編輯器就能打開看，
瀏覽器直接渲染。就算哪天這個站掛了、我不維護了，你的筆記還是一份能雙擊打開的檔案。

這跟存成任何私有格式是相反的哲學 —— 那些格式一旦離開原本的工具，就變成人質。

## 核心主張

- **筆記即檔案** —— 一個 HTML 檔，沒有資料庫、沒有 schema、沒有版本遷移
- **圖片即可編輯的圖層** —— 底圖和註解都是同一棵 SVG 樹裡的節點，不是壓平的像素
- **雲端即資料夾** —— 見下方

## 關斴「存到自己的 Google 雲端硬碟」

這個專案 2019 年的原始構想，就是想把筆記自動存進使用者自己的 Google 雲端文件，
讓資料的所有權留在使用者手上。當時的認知是：要串接 Google Drive 就必須用 Google API，
所以整個專案被寫成了 PHP 版本。

後來發現，這件事有一條更簡單、而且更符合原始精神的路：

> **把筆記直接存進你電腦上的「Google 雲端硬碟」資料夾，讓 Google Drive 桌面版去同步。**

同步這件事交給本來就在做同步的軟體，程式完全不需要知道雲端存在。
零 API、零 OAuth、零 GCP、零網路請求 —— 而原始目標（筆記自動出現在個人的 Google 雲端硬碟）
完全達成。

同一套做法對 Dropbox、OneDrive、iCloud 也通用：使用者想用哪個雲，就存進哪個資料夾，
程式一行都不用改。

這也把「可攜性」推到底了：連這個編輯器本身都不再是必要的一環。

## 關於名字

這個專案從 2019 年起就叫 **wripix** —— write + pixel，寫字跟畫圖在同一張紙上，
正好是這個編輯器在做的事（舊的部署還留在 `wripix.xyz`）。

中間一度想改名叫 flatnote，最後還是留在 wripix：repo、GitHub Pages 網址、
以及認識這個專案的人記得的，都是這個名字。

## 功能

**編輯**
粗體 / 斜體 / 底線 / 刪除線、三級標題、引用、程式碼區塊、項目與編號清單、
對齊、連結、清除格式。稿紙樣式三種：空白（口）、橫線（三）、方格（回）。

**檔案**
開新檔、開啟、儲存、另存新檔。`Ctrl+S` 存檔。
存過一次之後，狀態列會顯示「未儲存 / 已儲存」，改了什麼、存了沒有一眼就知道。
關掉瀏覽器再打開，會記得上次那個檔案，直接接著編輯。

**圖片與 SVG 註解**
按 🖼、直接貼上、或把圖片拖進來。圖片一律轉成 data URI 內嵌，永遠不會失聯。

點一下圖片進入註解模式，浮出工具列：

| 工具 | 說明 |
|---|---|
| ✎ | 手繪筆，拖曳畫自由線條 |
| ↗ | 箭頭，從 A 拖到 B |
| ▢ ◯ | 方框 / 橢圓，圈出一塊區域 |
| A | 文字標籤，點一下打字 |
| 顏色 | 紅 / 橘 / 藍 / 綠 / 黑 |
| · ● | 線條粗細 |
| ↶ ⌫ ✓ | 復原一筆 / 清空 / 完成（Esc） |

點既有的註解可以選取它，按 Delete 刪除，或直接換顏色。

註解的座標用圖片原始尺寸，所以圖片縮放時標記不會跑掉。
舊筆記裡的普通 `<img>` 點一下會自動升級成可註解的圖。

## 怎麼跑

**最簡單：** 直接開 https://pondahai.github.io/wripix/

GitHub Pages 全站強制 https，存檔功能可以直接用，不需要跑任何伺服器。

**本地跑：** 把 `index.html` 放進一個資料夾，然後

```
python -m http.server 8000
```

開 `http://localhost:8000`。

> ⚠️ **不能直接雙擊 `index.html`。**
> 瀏覽器規定「碰使用者硬碟」的能力只在安全來源（`https://` 或 `localhost`）下開放，
> `file://` 會被停用。程式偵測到 `file://` 時會主動提醒。

## 瀏覽器支援

直接寫回原檔用的是 [File System Access API](https://developer.mozilla.org/en-US/docs/Web/API/File_System_Access_API)，
目前只有 **Chrome / Edge** 支援。

Firefox / Safari 會自動退回「下載／上傳」模式，編輯功能完全正常，
只是儲存會變成下載一份新檔案。頁面頂端會出現提示。

## 技術

單一 HTML 檔，約 46KB，**零外部相依、零網路呼叫**。把網路線拔掉照常運作。

沒有 jQuery、沒有 medium-editor、沒有 svg.js —— 2019 年那版用的函式庫全部拿掉了。

| | |
|---|---|
| 編輯器 | `contenteditable` + `document.execCommand` |
| 存檔 | File System Access API |
| 記住檔案 | IndexedDB（存 `FileSystemFileHandle`）|
| 註解 | 原生 SVG DOM + Pointer Events |

## 檔案格式

存出去的是一份完整、可獨立開啟的 HTML 文件，內容包在 `<div id="note">` 裡，
樣式內嵌，並帶一個 `<!--dahai-notebook v1-->` 標記讓編輯器認得自己存的檔。

沒有這個標記的一般 HTML 檔也盡量讀得進來。
